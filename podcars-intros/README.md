# PodCars intros

Four 3-second intro options, 1080×1920, each with music and sound effects.

| Clip | Style | Source page |
|---|---|---|
| `podcars-intro-a-sunny-comic.mp4` | Sunny comic (used in the Car Talk film) | `car-talk/intro.html` |
| `podcars-intro-b-neon-night.mp4` | Neon night | `car-talk/intro-b.html` |
| `podcars-intro-c-road-sign.mp4` | Road sign | `car-talk/intro-c.html` |
| `podcars-intro-d-comic-panels.mp4` | Comic panels | `car-talk/intro-d.html` |

`all-four.film.html` is the OpenFilm timeline that plays all four back to back with their sounds. To use it, copy it into `car-talk/` as a project's `film.html`; it shows the sound timing for each intro.
